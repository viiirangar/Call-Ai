# Call-Ai · نسخهٔ خودمیزبان

پنل شخصی فرانسوی برای گفت‌وگو با یک مدل خودمیزبان، دیکتهٔ صوتی، ثبت یادداشت، استخراج متن PDF و جست‌وجو در حافظهٔ محلی. داده در SQLite روی دستگاه میزبان ذخیره می‌شود.

## اجرا روی سرور

پیش‌نیازها Node.js 24 و، برای PDF، فرمان `pdftotext` از Poppler هستند. در Ubuntu و Debian، فرمان `pdftotext` در بستهٔ `poppler-utils` قرار دارد. از یک حساب سیستم غیرمدیر استفاده کنید.

```bash
cd self-hosted
umask 077
touch .env
chmod 600 .env
```

در فایل محلی `.env`، متغیر `CALLAI_PASSWORD` را با یک رمز تصادفی قوی حداقل ۱۶ کاراکتری تنظیم کنید. این فایل را در Git قرار ندهید. سپس اجرا کنید.

```bash
node --env-file=.env start.mjs
```

آدرس پیش‌فرض `http://127.0.0.1:4400` است. اگر سرور راه دور است، برای تست خصوصی می‌توانید یک تونل SSH از رایانهٔ خودتان باز کنید.

```bash
ssh -L 4400:127.0.0.1:4400 USER@SERVER
```

برای دسترسی از مرورگر سامسونگ، یک پراکسی HTTPS به همین آدرس لوپ‌بک وصل کنید و `CALLAI_PUBLIC_ORIGIN` را دقیقاً روی آدرس HTTPS پنل، بدون `/` انتهایی، بگذارید. خود برنامه فقط روی لوپ‌بک گوش می‌دهد. `CALLAI_DATABASE` و `CALLAI_PORT` برای تغییر مسیر داده و پورت اختیاری‌اند. در استقرار دائمی، فایل پایگاه داده را بیرون از پوشهٔ checkout و در محل دارای پشتیبان نگه دارید.

PDF متنی حداکثر ۱۰ مگابایت پذیرفته می‌شود. متن استخراج‌شده در پایگاه داده ذخیره می‌شود و فایل اصلی نگه‌داری نمی‌شود. فایل PDF اسکن‌شده به OCR جداگانه نیاز دارد.

## اتصال گفت‌وگو و میکروفون

- برای گفت‌وگو، Ollama را روی همان میزبان اجرا کنید و یک مدل محلی نصب کنید. `CALLAI_MODEL` را در `.env` روی نام دقیق مدل نصب‌شده بگذارید. آدرس پیش‌فرض سرویس `http://127.0.0.1:11434` است. `CALLAI_OLLAMA_ORIGIN` برای تغییر پورت اختیاری است. دستیار حداکثر سه گزیدهٔ متنی منطبق را به‌عنوان زمینه برای مدل ارسال می‌کند.
- برای دیکته، `whisper-server` از whisper.cpp را با مدل چندزبانه و `--convert` اجرا کنید تا صدای مرورگر با ffmpeg پردازش شود. `CALLAI_WHISPER_ORIGIN=http://127.0.0.1:8080` را در `.env` تنظیم کنید. پنل صوت تا ۲۰ ثانیه را بعد از توقف برای تبدیل به متن می‌فرستد. قبل از ارسال پیام می‌توانید متن را اصلاح کنید. مرورگر روی دستگاه دیگر برای میکروفون به HTTPS نیاز دارد.
- دکمهٔ «Écouter en français» از صدای فرانسوی نصب‌شده و آفلاین مرورگر یا سیستم‌عامل استفاده می‌کند. صدای شخصی شبیه‌سازی‌شده و تماس سیم‌کارت در این نسخه در دسترس نیستند.

پس از تغییر `.env`، برنامه را دوباره اجرا کنید. Ollama و Whisper باید فقط روی لوپ‌بک گوش دهند. نشانی‌های سرویس در حالت فعلی به لوپ‌بک محدودند. پنل تنظیم‌شدن آدرس‌ها را نشان می‌دهد و دسترسی واقعی سرویس هنگام ارسال پیام یا دیکته بررسی می‌شود.
