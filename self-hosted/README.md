# Call-Ai · نسخهٔ خودمیزبان

سرور شخصی گفت‌وگو با مدل خودمیزبان، دیکتهٔ صوتی و حافظهٔ PDF. داده در SQLite روی دستگاه میزبان ذخیره می‌شود. برای نصب روی گوشی، [کلاینت بومی اندروید](android/README.md) را ببینید.

## اجرا روی سرور

پیش‌نیازها Node.js 24 و، برای PDF، فرمان `pdftotext` از Poppler هستند. در Ubuntu و Debian، فرمان `pdftotext` در بستهٔ `poppler-utils` قرار دارد. از یک حساب سیستم غیرمدیر استفاده کنید.

```bash
cd self-hosted
umask 077
touch .env
chmod 600 .env
```

در فایل محلی `.env`، متغیر `CALLAI_PASSWORD` را با یک رمز تصادفی قوی حداقل ۱۶ کاراکتری تنظیم کنید. این فایل را در Git قرار ندهید. سپس اجرا کنید.

```bash
node --env-file=.env start.mjs
```

آدرس پیش‌فرض `http://127.0.0.1:4400` است. اگر سرور راه دور است، برای تست خصوصی می‌توانید یک تونل SSH از رایانهٔ خودتان باز کنید.

```bash
ssh -L 4400:127.0.0.1:4400 USER@SERVER
```

برای اتصال اپ سامسونگ، یک پراکسی HTTPS به همین آدرس لوپ‌بک وصل کنید و `CALLAI_PUBLIC_ORIGIN` را دقیقاً روی آدرس HTTPS سرور، بدون `/` انتهایی، بگذارید. سرور Node فقط روی لوپ‌بک گوش می‌دهد. `CALLAI_DATABASE` و `CALLAI_PORT` برای تغییر مسیر داده و پورت اختیاری‌اند. در استقرار دائمی، فایل پایگاه داده را بیرون از پوشهٔ checkout و در محل دارای پشتیبان نگه دارید.

PDF متنی حداکثر ۱۰ مگابایت پذیرفته می‌شود. متن استخراج‌شده در پایگاه داده ذخیره می‌شود و فایل اصلی نگه‌داری نمی‌شود. فایل PDF اسکن‌شده به OCR جداگانه نیاز دارد.

## اتصال گفت‌وگو و میکروفون

- برای NVIDIA NIM، کلید و نام دقیق مدل را از [کاتالوگ NVIDIA](https://build.nvidia.com/) بگیرید و در تنظیمات اپ وارد کنید. برای ارائه‌دهندهٔ دیگر، آدرس HTTPS عمومی، نام مدل و کلید Bearer رابط `chat/completions` سازگار با OpenAI را بگذارید. اگر یک میزبان سفارشی صرفاً IPv6 داشته باشد، این نسخه به آن وصل نمی‌شود.
- کلید در SQLite روی سرور رمزگذاری می‌شود و از API دوباره خوانده نمی‌شود. برای جدا ماندن رمز ورود از کلید رمزگذاری، قبل از اولین ذخیرهٔ BYOK می‌توانید `CALLAI_BYOK_SECRET` را با یک مقدار تصادفی مستقل در `.env` تنظیم کنید. این مقدار را با دسترسی محدود نگه دارید. در غیاب آن، رمز ورود مبناست. بعد از تغییر مقدار مبنا، کلید API را دوباره در اپ ثبت کنید.
- مدل راه‌دور پیام و حداکثر سه گزیدهٔ منطبق از حافظه را دریافت می‌کند. در صورت تنظیم BYOK، نصب Ollama برای گفتگو لازم نیست. برای استفاده از مدل محلی اختیاری، `CALLAI_MODEL` و در صورت نیاز `CALLAI_OLLAMA_ORIGIN` را در `.env` تنظیم کنید. آدرس پیش‌فرض مدل محلی `http://127.0.0.1:11434` است.
- برای دیکته، `whisper-server` از whisper.cpp را با مدل چندزبانه و `--convert` اجرا کنید تا صدای دستگاه با ffmpeg پردازش شود. `CALLAI_WHISPER_ORIGIN=http://127.0.0.1:8080` را در `.env` تنظیم کنید. اپ پس از توقف، صوت ضبط‌شده تا ۲۰ ثانیه را برای تبدیل به متن می‌فرستد. قبل از ارسال پیام می‌توانید متن را اصلاح کنید.
- دکمهٔ «Écouter en français» از صدای فرانسوی نصب‌شده و آفلاین دستگاه استفاده می‌کند. صدای شخصی شبیه‌سازی‌شده و تماس سیم‌کارت در این نسخه در دسترس نیستند.

پس از تغییر `.env`، برنامه را دوباره اجرا کنید. Ollama و Whisper باید فقط روی لوپ‌بک گوش دهند. نشانی‌های سرویس در حالت فعلی به لوپ‌بک محدودند. پنل تنظیم‌شدن آدرس‌ها را نشان می‌دهد و دسترسی واقعی سرویس هنگام ارسال پیام یا دیکته بررسی می‌شود.
