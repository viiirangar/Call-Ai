# دستیار شخصی اندروید ۰٫۱

نسخهٔ آزمایشی دیکتهٔ فرانسوی و ذخیرهٔ متن روی دستگاه. حداقل نسخهٔ سیستم‌عامل اندروید ۱۳ است. دیکته از سرویس تشخیص گفتار روی دستگاه استفاده می‌کند و به عرضهٔ مدل فرانسوی روی گوشی بستگی دارد. دکمهٔ `Installer le modèle français` درخواست دریافت مدل را به اندروید می‌دهد. اپ مجوز اینترنت ندارد و فایل صوتی ذخیره نمی‌کند.

## آزمایش روی گوشی

1. APK را باز کنید، اپ را نصب کنید و پس از انتخاب `Dicter en français` مجوز میکروفون را بدهید.
2. جملهٔ `Bonjour, je voudrais confirmer le rendez-vous de jeudi à dix heures.` را بگویید و متن را بررسی کنید. اگر مدل در دسترس نیست، دکمهٔ نصب مدل را بزنید.
3. روی `Enregistrer la note` بزنید. اپ را ببندید و دوباره باز کنید تا ماندگاری یادداشت را ببینید.

## ساخت دوباره روی ویندوز

اسکریپت `build.ps1` به JDK، پوشهٔ Android SDK Platform 35 و پوشهٔ Android SDK Build-Tools 35.0.0 نیاز دارد. `BuildDir` را برای هر نسخهٔ آزمایشی در یک مسیر ثابت نگه دارید تا همان کلید آزمایشی استفاده شود. کلید خصوصی در این بسته قرار ندارد.

```powershell
.\build.ps1 -Platform 'C:\Android\Sdk\platforms\android-35' `
    -BuildTools 'C:\Android\Sdk\build-tools\35.0.0' `
    -Jdk 'C:\Program Files\Android\Android Studio\jbr' `
    -BuildDir "$PWD\build" -OutputApk "$PWD\Assistant-Android.apk"
```

## مسیر تماس سیم‌کارت

نسخهٔ ۰٫۱ به صدای تماس سیم‌کارت دسترسی ندارد. برای مسیر خودمیزبان، یک آزمایش بعدی با Asterisk و `chan_mobile` روی میزبان لینوکسی دارای بلوتوث، در برد فیزیکی گوشی، پیشنهاد شده است. سازگاری صوت دوطرفه و شماره‌گیری با گوشی و خط Proximus باید روی دستگاه واقعی بررسی شود. اگر سرور در دیتاسنتر باشد، پل بلوتوث باید روی یک دستگاه محلی کنار گوشی اجرا شود. پنل، حافظهٔ مدارک و صدای شبیه‌سازی‌شده به نسخه‌های بعدی تعلق دارند.
